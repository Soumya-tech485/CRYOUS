# Design Rules

1. One module = One responsibility.

2. Brain never accesses hardware directly.

3. Agents never communicate directly.

4. Every request starts from Command Center.

5. Memory stores data only.

6. Voice only handles speech.

7. Browser only handles internet.

8. Settings never contain business logic.

9. Every module should be replaceable without changing the whole system.

10. Every folder should have a README explaining its purpose.
