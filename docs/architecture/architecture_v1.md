# CRYOUS Architecture v1.0

## Vision

CRYOUS is an AI Operating System, not just an AI assistant.

The goal of CRYOUS is to understand users, reason like a human, plan tasks, use specialized agents, control devices, perform research, remember information, and continuously improve itself.

---

## Core Principles

1. Every module has only one responsibility.
2. Brain never directly performs tasks.
3. Command Center is the only entry point.
4. Agents never communicate directly.
5. Agent Manager controls all agents.
6. Memory stores information.
7. Device modules only interact with hardware.
8. Configuration never contains business logic.
